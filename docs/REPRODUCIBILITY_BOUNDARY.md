# Reproducibility boundary

## What can be reproduced?

The displayed numeric values can be traced to retained summary cells with unit conversion/rounding and selectors. Original figure PDFs/table sources are available; a presentation helper is supplied for later use with stored summaries. Its execution was not part of this preparation. No statistical estimate has been regenerated.

## What can be inspected?

Production source changes and custom code, historical metric/statistics helpers, executed production configuration/CRN records, production/supporting run identities, canonical outputs and all primary metric definitions. Session-recovered production helpers are explicitly distinguished from Git-tracked files. Their public copies remove local paths; original and public hashes are recorded separately.

## What cannot be recreated exactly, and why?

The contemporaneous original executable checksum, executed antenna runtime attributes, executed S1-U/S5 runtime attributes and a complete historical dependency lock are unavailable. A current binary hash cannot establish historical binary identity. Source defaults are not executed settings. Production exploratory application tails use the full trace; new intermediate-load exploratory tails use first reception in [15,120). Their p99/worst-UE trends are not uniform-window comparisons.

Raw event traces and the complete original environment are not shipped. An executable build and raw-to-metric replay are not validated by this package. Operational UTM behavior is outside the study.

## Does this affect primary numeric traceability?

These gaps limit independent reconstruction of the historical simulation, but do not prevent checking which stored canonical cells support each main result. Such checking verifies traceability, not independent recomputation or validation of the simulator. Raw-to-metric validation would require the retained raw inputs and additional environment work.
